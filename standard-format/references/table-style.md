# 统一表格规范

本文件定义所有交付格式共用的表格规则。颜色、字体和数字格式引用 `references/theme-style.md`。HTML、Excel、Word、PPT、PDF必须从以下表格类型中选择，不得临时创造新样式。

## 通用硬规则

- 每张表必须有中文表题、明确列名、单位或口径说明、数据截止日和来源说明。
- 列名必须能独立解释字段含义，不使用“值1”“结果”“指标A”等占位名称。
- 数值列右对齐或居中，文本列左对齐，日期列居中。
- 表格不得用图片替代，除非原表无法结构化且已通过清晰度验收。
- 缺失值写NA，不适用写不适用，零值写0。
- 可见文案不得使用竖线分隔符。括号只用于单位、公式、缩写首次定义和必要引用。
- 表格颜色必须使用 `theme-style.md` token，不得只写泛称颜色。

## 三线表结构

所有格式的表格统一采用黑色三线表，线色、线宽和表头处理不因格式改变。

- 只保留三条主线：表格顶线、表头下线、表格底线。
- 线色一律RULE_BLACK #000000。顶线和底线1.5磅或1.5px，表头下线0.75磅或1px。
- 不画竖线。正文行之间不画横线。
- 分组汇总行上方允许加一条RULE_BLACK #000000分组线，0.5磅或1px，全表最多3条，超过说明表格该拆。
- 表头无底色，只靠加粗和表头下线区分。不使用NOTE_BG、CALC_FILL、SERIES_BENCH_DEEP或任何填充色做表头。唯一例外是HTML滚动容器内的sticky表头，必须给PANEL底色遮挡滚动内容。
- 语义色只用于单元格文字，不用于整行整列填充。需要突出的行改用文字加粗，最多突出3行。

## 固定表格类型

| 表格类型 | 适用场景 | 固定列 | 行数上限 |
|---|---|---|---:|
| 指标汇总表 | 策略收益风险、年度表现、风险预算摘要 | 策略、期末净值、年化收益、年化波动、最大回撤、夏普、卡玛、换手 | HTML 12行，PPT 10行，Word 30行，PDF 30行 |
| 参数表 | 数据口径、交易成本、信号参数、约束条件 | 环节、参数、当前值、默认值、允许范围、单位、规则或公式、选值依据 | HTML 20行，PPT 14行，Word 30行，PDF 30行 |
| 长文本对比表 | 差异来源、信号取舍、风险边界 | 对象、判断、证据、影响、处理方式 | HTML 12行，PPT 8行，Word 20行，PDF 20行 |
| 明细数据表 | 月度、年度、交易、样本明细 | 日期、对象、分类、指标值、变化、状态、说明 | HTML 50行，PPT 12行，Word 50行，PDF 50行 |
| 归因表 | 资产、因子、阶段、交易成本归因 | 归因维度、归因对象、期初权重、期末权重、收益贡献、配置贡献、交易贡献、累计贡献、说明 | HTML 20行，PPT 10行，Word 30行，PDF 30行 |
| 敏感性摘要表 | 参数敏感性图前置解释 | 参数、当前值、收益最高、回撤最浅、夏普最高、结论 | HTML 12行，PPT 8行，Word 20行，PDF 20行 |
| 数据字典表 | 字段说明和数据血缘 | 字段、含义、类型、单位、来源、计算口径、缺失值处理 | HTML 50行，PPT只放关键字段，Word附录不限但需跨页表头 |
| 验收清单表 | 格式、数据、图表、公式检查 | 检查项、标准、结果、说明 | HTML 20行，PPT 10行，Word 30行，PDF 30行 |

超过上限时必须拆表、移入附录、转Excel或另交CSV，不得压缩字号硬塞。

## HTML表格

- 普通表格字号12.5px，行高1.48，单元格内边距8px 10px。
- 紧凑表字号12px，行高1.42，单元格内边距6px 8px。
- 长文本表字号12.5px，行高1.55，文本列允许换行。
- 顶线RULE_BLACK #000000实线1.5px，表头下线RULE_BLACK #000000实线1px，底线RULE_BLACK #000000实线1.5px。不画竖线，正文行之间不画横线。
- 表头无底色。放入`.scroll`的宽表和长表，sticky表头必须给PANEL底色遮挡滚动内容，不使用其他填充色。
- 行悬停底色ROW_HOVER，只用于可交互长表，静态汇总表不加。
- 表格首列颜色TEXT_SECONDARY，字体半粗。
- 正贡献、增强项、核心结果用SERIES_MAIN；回撤改善和亏损收缩用SERIES_DEFENSE；基准和对照用SERIES_BENCH；缺失值用MISSING_GREY #A6A6A6。
- 宽表必须放入`.scroll`，最大高度460px，横向溢出由滚动容器承接。
- `.scroll`内部表头必须sticky，`top:0`，`z-index:1`。
- 表格前必须有`.ch`卡片标题或小节说明，表格后注释使用`.table-note`，字号12px到12.5px。

## Excel表格

- 中文标题宋体加粗14到16磅，中文正文和表格宋体10到11磅，英文和数字Arial10到11磅。
- 表头无底色，仅加粗，字体INK。三线用单元格边框实现：表头行上边框RULE_BLACK #000000粗线，表头行下边框RULE_BLACK #000000细线，数据区末行下边框RULE_BLACK #000000粗线。表格区域关闭默认网格线显示。
- 功能区底色只用于标识区域属性，不是表头样式：参数输入区INPUT_FILL #FFF2CC；公式计算区CALC_FILL #DDEBF7；数据来源区SOURCE_FILL #F2F2F2；风险阈值WARNING_FILL。
- 明细表、数据表、参数表、数据字典必须启用筛选。
- 明细表冻结首行和前两列；指标汇总表冻结首行；参数表和数据字典冻结首行。
- 表头不得为空、合并或跨空行。
- 日期列宽12，代码列宽12，名称列宽16，分类列宽14，数值列宽12，金额列宽14，说明列宽30到45。
- 标题行高24到28，表头行高20到24，普通数据行高18到20，说明行高30到60。
- 公式区不得手工覆盖；关键参数必须引用参数表，不在公式中硬编码。

## Word表格

- 表题置于表格上方，格式为“表3-1策略表现汇总”。
- 表注置于表格下方，字号8到9磅。
- 表格正文10到10.5磅，中文宋体，英文和数字TimesNewRoman或Arial。
- 使用黑色三线表。顶线RULE_BLACK #000000，1.5磅；表头下线RULE_BLACK #000000，0.75磅；底线RULE_BLACK #000000，1.5磅。
- 不使用竖线，正文行之间不使用横线。分组汇总行上方可加RULE_BLACK #000000，0.5磅分组线，全表最多3条。
- 表头无底色，仅加粗。不使用NOTE_BG、CALC_FILL或任何填充色做表头。
- 突出行只用文字加粗或语义色文字，不用整行填充。
- 跨页表必须重复表头，并在续表页标注“表3-1续”。
- 宽表优先横向页面或附录，不得把字号压低到9磅以下。

## PPT表格

- 主文表格列数不超过8列，行数不超过12行。超过即拆页、移入附录或交Excel。
- 表格区域默认x=0.75英寸，y=1.35英寸，w=11.85英寸，h=5.55英寸。
- 使用黑色三线表。顶线RULE_BLACK #000000，1.5磅；表头下线0.75磅；底线1.5磅。不使用竖线和正文行横线，表头无底色，仅加粗。
- 正向数据用SERIES_MAIN，负向或亏损用SERIES_DEFENSE，基准或对照用SERIES_BENCH。
- 表格正文至少10磅，关键结果至少12磅。单元格文字超过两行必须缩短或拆页。
- 每张表最多突出3行，突出方式为文字加粗，不使用整行填充。
- 投影环境下靠字号、加粗和三线区分层次，不靠深底表头。

## PDF表格

- 正式PDF表格必须可搜索、可复制，不得整表截图。
- A4纵向正文表格不超过8列；宽表使用A4横向、拆表或附录。
- 表格正文不低于10磅，表注不低于8磅。
- 使用黑色三线表。顶线RULE_BLACK #000000，1.5磅；表头下线RULE_BLACK #000000，0.75磅；底线RULE_BLACK #000000，1.5磅。不使用竖线和正文行横线，表头无底色。
- 跨页表必须重复表头。表题、表身、表注尽量作为一个单元，不在表题后立即分页。
- TeX PDF优先使用booktabs、longtable或tabularx，三线对应`\toprule`、`\midrule`、`\bottomrule`，分组线用`\cmidrule`，禁用`\hline`和竖线列格式。Word PDF沿用Word表格规则。HTML PDF沿用HTML表格规则。

## 验收清单

- 表格类型是否来自固定矩阵。
- 是否为三线结构：有且只有顶线、表头下线、底线，无竖线，无正文行横线。
- 三线是否全部为RULE_BLACK #000000，五种格式是否一致。
- 表头是否无底色，是否存在整行整列填充。
- 表头、单位、口径、来源、数据日期是否完整。
- 字号、行高、列宽、线条和底色是否符合目标格式。
- 数字小数位是否统一。
- 缺失值、不适用和零值是否区分。
- 行列数量是否超过目标格式上限。
- 宽表和长表是否转入滚动、附录、Excel或CSV。
- 颜色是否全部来自 `theme-style.md` token。
