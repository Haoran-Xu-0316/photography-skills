# PPT 模板规范

本文件只定义PPT展示形式。文字口径、分析结构、标题表达、标点和括号规则统一使用 `references/writing-style.md`。

使用本文件前，必须同时读取 `references/theme-style.md`、`references/chart-style.md` 和 `references/table-style.md`。颜色、图表和表格的共用规则以这三份文件为准，本文件只补充当前格式的承载方式。

## 参考模板

默认PPT输出复制 `assets/ppt-template/standard-ppt-template.pptx`。该文件是真实pptx模板，实际生成时必须替换为当前项目结论、图表和数据。

## 模板化配置接口

PPT必须像HTML一样有母版配置接口，不能每页临时设计。

### 主题接口

PPT主题执行 `references/theme-style.md`，并固定如下：

- 主色：SERIES_MAIN，用于核心结论、增强策略、正贡献和重点箭头。
- 对照色：SERIES_BENCH，用于基准、原策略和历史对比。
- 强调色：SERIES_ACCENT，用于章节号、关键分隔线和少量提示。
- 防御色：SERIES_DEFENSE，用于回撤收窄、风险下降和负向改善。
- 风险色：SERIES_RISK，用于压力情景、异常暴露和风险因子。
- 中性色：MUTED和SERIES_NEUTRAL，用于注释、页脚、辅助线和非重点文本。
- 用户要求“用XX配色”时，只改 `theme-style.md` token，不改页型结构和图表版式。

### 母版接口

- 默认比例为16:9，页面尺寸13.333英寸×7.5英寸。
- 页面背景固定为PANEL，正文浅底固定为SOURCE_FILL #F2F2F2。
- 左右安全边距0.55英寸，上安全边距0.35英寸，底部安全边距0.25英寸。
- 标题区高度0.55英寸，主体内容区顶部1.10英寸，页脚区顶部7.10英寸。
- 标题固定左上，页码固定右下或页脚右侧。
- 所有页面必须使用同一套母版，不得单页改变标题位置、页脚位置和页码位置。
- 页面不得堆叠装饰性卡片。卡片只用于指标摘要、结论突出或必要信息分组。

### 字体和字号

- 默认中文标题和正文字体均为宋体，标题靠字号和加粗区分层级。
- 英文和数字使用Arial；需要正文型长句时可使用TimesNewRoman。
- 封面主标题28到34磅，章节页标题28到32磅，正文页标题22到26磅。
- 核心结论20到24磅，正文14到16磅，图表标题13到15磅。
- 坐标轴、图例、数据标签和表格正文10到12磅。
- 页脚和数据来源8到9磅。
- 单页正文不超过6行，每行不超过28个汉字。
- 单个文本框不同时使用超过两种字号。
- 关键数字可加粗，但加粗范围不得超过页面文字总量20%。

## 页型矩阵

### 封面页

- 内容：报告标题、研究主题、汇报机构或团队、日期。
- 标题最多两行，位于页面左侧或中部偏左区域。
- 标题与副标题间距不低于0.18英寸。
- 日期和机构信息置于左下方或右下方，字号8到10磅。
- 不放目录、摘要、核心指标和大段说明。
- 背景可用高质量图片或简洁图形，但不得降低标题可读性。

### 目录页

- 适用于10页以上PPT。
- 目录不超过6个一级章节。
- 一级章节使用一、二、三或1、2、3，全稿一致。
- 二级章节仅在汇报时间超过20分钟时使用。
- 每个目录项保持单行。
- 当前章节使用SERIES_MAIN高亮，其他章节使用TEXT_SECONDARY。
- 目录页不放章节摘要、结论或图表。

### 章节页

- 每个一级章节使用独立章节页。
- 只保留章节编号、章节标题和一句必要定位语。
- 章节标题28到32磅。
- 不放完整图表、表格和长段正文。
- 章节页背景与正文页保持统一，不使用独立主题。

### 核心结论页

固定结构：页面标题、一句话核心结论、2到4条证据、必要图表或指标。

- 核心结论距标题0.18到0.28英寸，最多两行。
- 每条证据不超过两行。
- 核心数字至少20磅。
- 结论页必须能独立理解。
- 结论必须与图表方向一致，不能出现文字结论与图形走势相反。

### 单图页

- 固定结构：页面标题、一句图表解读、主图、数据来源和口径说明。
- 单图占主体内容区宽度80%以上或高度65%以上。
- 一页只保留一个核心问题。
- 图表标题不得替代页面标题。
- 最多突出3个时间点、区间或拐点。
- 数据标签只标注起点、终点、极值点、政策节点或核心事件。

### 双图页

- 默认左右双列结构。
- 两图宽度相等，顶部和底部对齐。
- 两图时间区间、坐标轴、单位和图例位置必须一致；无法一致时拆成两页。
- 每张图下方最多两行解读。
- 不得将两个无关图表强行放在同一页。
- 若共用横轴，必须共享横轴并减少重复标注；无法共享时分拆页面。

### 四图页

- 默认2×2网格，间距0.18到0.24英寸。
- 四图尺寸一致，每张图必须有独立标题。
- 四图使用同一颜色逻辑和时间轴口径。
- 每张图的数据标签不超过3个。
- 四图页只用于概览、筛选或固定检验模板。
- 单图文字低于10磅时，必须拆为双图页或多页。

### 表格页

- 默认列数不超过8列，行数不超过12行。
- 超过限制时拆页、移入附录或只保留重点行。
- 使用黑色三线表。顶线RULE_BLACK #000000，1.5磅；表头下线0.75磅；底线1.5磅。表头无底色仅加粗，正文不使用交替底色。
- 表格正文至少10磅，关键结果至少12磅。
- 数字右对齐，文字左对齐。
- 百分比保留1位小数，金额和指数按数据精度统一。
- 正向数据用SERIES_MAIN，负向数据用SERIES_BENCH或SERIES_DEFENSE，零值用TEXT_SECONDARY。
- 每张表最多突出3行，突出方式为文字加粗，不使用整行填充。
- 不使用竖向网格线和正文行横线，只保留三线和分组线。
- 页脚必须注明数据来源、统计口径和单位。

### 流程图页

- 用于策略框架、信号生成、组合构建和风险控制。
- 流程方向默认从左至右或从上至下，只选一种。
- 流程节点不超过7个，每个节点最多两行文字。
- 节点宽度和高度保持一致。
- 判断节点、数据节点、动作节点可使用不同形状，形状种类不超过3种。
- 主流程使用SERIES_MAIN，辅助流程使用CALC_FILL #DDEBF7或GRID_LINE，风险拦截使用SERIES_MAIN_DEEP。
- 复杂流程拆分为输入、处理、输出、约束四层。
- 禁止使用交叉连接线。

### 敏感性分析页

- 固定包含基准情景、上行情景、下行情景、关键参数、结果指标和变化方向。
- 默认使用二维敏感性矩阵或情景柱状图。
- 二维矩阵行列变量必须标注单位。
- 基准情景使用SERIES_BENCH_DEEP边框或CALC_FILL #DDEBF7底色。
- 色阶不超过5档。
- 敏感性区间必须标明参数范围和步长。
- 不得只展示最优情景，不得隐藏基准情景和不利情景。
- 必须注明固定参数、变量参数和计算假设。

### 结论边界页

- 固定结构：适用条件、失效情景、数据与模型限制、执行和监控要求。
- 适用条件和失效情景分列展示。
- 每类边界不超过4条，每条不超过两行。
- 必须明确哪些结论是统计关系，哪些结论是投资判断。
- 风险边界应对应可观测指标、阈值或触发条件。

### 附录页

- 用于方法细节、变量定义、完整回测结果和补充图表。
- 附录标题18到22磅。
- 附录正文和表格字号可比主文降低1到2磅，但不得低于10磅。
- 附录图表必须保留标题、单位、数据来源和口径。
- 附录不放置主文未提及的大量新结论。

## 图表规范

PPT图表执行 `references/chart-style.md`，并补充以下页面规则。

### 图表类型

- 时间序列使用折线图。
- 横截面比较使用水平条形图。
- 收益贡献使用正负条形图。
- 结构占比使用堆叠条形图，类别不超过5类时可用环形图。
- 相关性分析使用热力图。
- 风险收益比较使用散点图。
- 回撤分析使用面积图或折线图。
- 事件影响使用事件标记折线图。
- 禁止三维图、立体柱状图、仪表盘式图形和无明确含义的雷达图。

### 图表页细节矩阵

- 单图页：主图区域x=0.75英寸、y=1.45英寸、w=11.8英寸、h=4.85英寸。标题下方只放一句解读，不放多段背景。
- 双图页：左右图区域各w=5.55英寸、h=4.45英寸，左右间距0.35英寸，两图标题和图例高度一致。
- 四图页：2×2网格，单图w=5.55英寸、h=2.35英寸，间距0.22英寸，只用于固定检验和概览。
- 表格页：表格区域x=0.75英寸、y=1.35英寸、w=11.85英寸、h=5.55英寸。超过8列或12行必须拆页。
- 敏感性页：上方放情景摘要，下方放矩阵或两张情景柱状图，基准情景必须可见。

### 坐标轴和图例

- 坐标轴线使用MUTED，线宽0.75磅。
- 网格线使用GRID_LINE，线宽0.5磅，只保留水平主网格线。
- 横轴标签默认不超过8个，纵轴刻度默认不超过6个。
- 纵轴必须注明单位，百分比、倍数、点位和金额不得混用。
- 多序列图必须使用同一坐标尺度。确需双轴时，必须在轴标题中明确标注单位和对象。
- 图例默认置于图表上方，横向排列。图例项目不超过6个，超过时合并类别或拆分页面。

### 数据标签和注释

- 数据标签只标注关键点，不标注所有数据点。
- 单图数据标签最多8个，四图页每张图最多3个。
- 标签不得遮挡数据线、柱体和其他标签。
- 注释线使用GRID_LINE，注释文字使用TEXT_SECONDARY。
- 政策、事件和回测区间使用统一注释样式。
- 图表中出现的缩写、指数代码和参数名称必须在首次出现时说明。

## 表格和指标规则

- 收益率统一使用百分比。
- 年化收益、波动率、最大回撤和夏普比率必须注明统计区间。
- 夏普比率必须注明无风险利率假设。
- 最大回撤必须明确使用净值序列或累计收益序列计算。
- 回测结果必须区分样本内、样本外和全样本。
- 组合收益、基准收益和超额收益必须使用一致的复权和再平衡口径。
- 单位、币种、价格类型和数据频率必须在表格或页脚中明确。
- 指标名称不得在同一份PPT中重复使用不同定义。

## 页脚和页码

- 页脚固定包含数据来源、样本区间、统计口径和页码。
- 页脚字号8到9磅。
- 数据来源置于左下角，页码置于右下角。
- 页脚与主体内容之间使用GRID_LINE横线分隔。
- 页脚不得超过两行。
- 每页页脚位置固定，不随图表大小变化。
- 涉及预测、回测或模拟结果时，页脚必须注明“历史表现不代表未来表现”。
- 数据截至日期必须使用完整日期格式。

## 公式规范

- PPT中的公式使用PowerPoint原生公式、矢量公式对象或可编辑数学对象。
- 不使用截图公式、低清晰度图片公式或代码块公式。
- 公式字号不低于14磅，变量解释不低于10磅。
- 单页公式不超过2个，复杂推导放入附录页或改用Word、PDF正文承载。
- 公式位于页面主体区中上部或图表下方说明区，不贴边，不遮挡图表。
- 公式编号可使用“式1”“式2”，用于全稿引用时必须连续。
- 核心变量必须在公式旁用短句或两列表说明，不让读者自行推断。
- 汇报页只保留决策必要公式，完整推导放附录。

## 导出PDF规范

- 导出比例固定为16:9。
- 优先导出标准质量PDF，禁止使用截图拼接PDF。
- 导出前嵌入字体，或确认接收端具备同名字体。
- 图表、公式和文字必须保持矢量清晰度。
- 页面不得出现字体替换、文字溢出、图形错位和透明度异常。
- 超链接、目录跳转和页码应在PDF中保持可用。
- PDF文件不得包含隐藏页面、批注、修订痕迹和临时对象。
- 发送前检查首页、章节页、图表密集页、表格页、附录页和最后一页。

## 文件命名

- 正式PPT命名使用 `报告名称_汇报主题_YYYYMMDD_v01.pptx`。
- 导出PDF命名使用 `报告名称_汇报主题_YYYYMMDD_v01.pdf`。
- 日期使用汇报日或数据截止日，全项目保持同一口径。
- 不使用“最终版”“最新版”“修改后”“汇报版”等不可追踪名称。
- 同一PPT连续修改时必须递增版本号。

## 固定默认值

### 页面默认值

- 页面比例：16:9。
- 页面尺寸：13.333英寸×7.5英寸。
- 左右边距：0.55英寸。
- 上边距：0.35英寸。
- 标题区高度：0.55英寸。
- 主体内容区顶部：1.10英寸。
- 页脚区顶部：7.10英寸。
- 页面背景：PANEL。
- 浅色分区底：NOTE_BG。

### 图表默认值

- 主序列：SERIES_MAIN。
- 对照序列：SERIES_BENCH。
- 上涨或正向：UP_TONE。
- 下跌或负向：DOWN_TONE。
- 风险或异常：SERIES_RISK。
- 主线宽度：1.75磅。
- 对照线宽度：1.00磅。
- 网格线：GRID_LINE，0.5磅。
- 图例位置：图表上方。
- 数据标签：仅标注关键点。

### 表格默认值

- 表头：无底色，文字INK加粗。
- 三线：RULE_BLACK #000000，顶线和底线1.5磅，表头下线0.75磅。
- 正文：无交替底色，无竖线，无行横线。
- 正文字号：10到12磅。
- 默认列数：不超过8列。
- 默认行数：不超过12行。
- 百分比精度：1位小数。
- 竖向网格线：不使用。

## 统一文字规则

- 使用 `references/writing-style.md` 的统一文字和内容规则。
- 本节不单独定义文风，只补充PPT承载方式。

## 验收清单

### 页面结构

- 页面比例是否统一为16:9。
- 所有页面是否使用统一母版。
- 标题位置、页脚位置和页码位置是否一致。
- 所有内容是否位于页面安全区内。
- 每页是否只表达一个主要问题。
- 目录编号与章节编号是否一致。
- 主文与附录引用关系是否清晰。

### 文字和排版

- 标题是否不超过两行。
- 正文是否无大段堆叠。
- 正文字号是否不低于14磅。
- 图表和表格文字是否不低于10磅。
- 数字、单位、小数位和对齐方式是否统一。
- 文字是否没有遮挡、溢出和截断。
- 可见文案是否出现竖线分隔符或过多括号。

### 图表和表格

- 图表类型是否与分析目的匹配。
- 坐标轴、单位、图例和数据来源是否完整。
- 图表颜色是否遵循统一口径。
- 数据标签是否遮挡图形。
- 表格列数和行数是否超出默认值。
- 回测、预测和模拟结果是否标注样本区间及统计口径。
- 敏感性分析是否展示基准、上行和下行情景。
- 结论边界是否说明适用条件和失效条件。

### 导出质量

- PDF页面数量是否与PPT一致。
- PDF中是否无字体替换和乱码。
- 图表和公式是否清晰可读。
- 超链接和目录跳转是否有效。
- 是否无隐藏页面、批注、修订痕迹和临时对象。
- 首页、核心结论页、图表页、表格页和附录页是否已逐页检查。
- 文件名是否符合统一命名规则。
- 数据截至日期和来源信息是否完整。
