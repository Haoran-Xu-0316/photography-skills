# 蓝晒植物印相

将植物主题或参考图表现为普鲁士蓝底、浅色植物负像的接触印相，呈现透光层次、纸纤维和不规则感光涂布边缘。

## 输入与输出

输入植物主题或参考照片，可指定枝叶数量、布局和纸张边缘。输出一张蓝晒风格图片。

## 使用示例

> 做一张蕨叶与两枝细草的蓝晒印相，深蓝底、浅色植物负像，保留纸边，不加标题。

使用时提供主题或参考图片，由具备图像生成与查看能力的模型按[执行说明](SKILL.md)完成。

## 使用说明

图片是生成式艺术表达，不是实际化学印相，也不能用于植物品种或叶序鉴定。


## 适合什么任务

适合植物艺术挂画、蓝白装饰图和接触印相风格创作。视觉核心是深蓝曝光底与浅色植物遮光痕迹，植物保持平面形态，纸边呈现不规则感光涂布。

## 如何准备素材和选择设置

可提供植物名称、枝叶照片或简单构图描述。说明主枝方向、植物组数、疏密和是否保留纸边即可。默认3:4竖版、一至三组植物、无文字；参考照片越清楚，叶序和分枝越容易核对。

## 完整请求示例

> 用一枝银杏和两枝细草做3:4竖版数字蓝晒，主枝向右上伸展，左侧保留较大蓝色空白，露出自然纸边，不加标题。

这段请求可连同素材交给能读取本目录[执行说明](SKILL.md)的模型。图片处理需要相应Python依赖；生成式图片需要运行环境提供生图能力。文字对话本身不等于已经执行处理。

## 如何阅读和验收结果

交付蓝晒风格图片。查看细茎是否断裂、植物是否像平面负像、重叠处透光是否自然。示例展示数字效果，不证明实际化学冲印过程，也不保证植物分类准确。
