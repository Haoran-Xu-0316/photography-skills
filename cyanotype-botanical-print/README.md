# 蓝晒植物印相

将植物主题或参考图表现为普鲁士蓝底、浅色植物负像的接触印相，呈现透光层次、纸纤维和不规则感光涂布边缘。

## 输入与输出

输入植物主题或参考照片，可指定枝叶数量、布局和纸张边缘。输出一张蓝晒风格图片。

## 使用示例

> 做一张蕨叶与两枝细草的蓝晒印相，深蓝底、浅色植物负像，保留纸边，不加标题。

使用时提供主题或参考图片，由具备图像生成与查看能力的模型按[执行说明](SKILL.md)完成。

图片是生成式艺术表达，不是实际化学印相，也不能用于植物品种或叶序鉴定。
