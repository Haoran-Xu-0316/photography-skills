# 照片几何校正

校正可定义、可复现的几何关系，包括水平倾斜、四点透视和基于真实标定参数的镜头几何畸变。

## 输入与输出

输入为照片及对应几何参数。输出校正副本和报告JSON，记录变换矩阵、输出尺寸和无效边裁切范围。

## 使用示例

> 按确认的倾斜角度扶正照片，裁掉无效边，另存校正结果。

提供照片与需求后，按[执行说明](SKILL.md)处理。Python调用方式见[函数示例](examples/basic_usage.py)。

## 使用说明

透视校正需确认四点顺序；镜头畸变校正需要真实标定参数。


## 适合什么任务

适合地平线扶正、建筑立面或画框的平面透视校正，以及有标定资料的镜头畸变修正。变换参数和裁边范围都会写入报告，便于复现。

## 如何准备素材和选择设置

扶正需确认角度或检测到的水平线；透视需确认平面四角和顺序；镜头校正需真实相机矩阵与畸变系数。画面中的斜线不一定是地平线，自动建议必须结合照片判断。

## 完整请求示例

> 把这张画框照片按我标出的四个角校正为正面矩形，保留画框内部完整内容，另存结果，并记录变换矩阵和最终尺寸。

这段请求可连同素材交给能读取本目录[执行说明](SKILL.md)的模型。图片处理需要相应Python依赖；生成式图片需要运行环境提供生图能力。文字对话本身不等于已经执行处理。

## 如何阅读和验收结果

查看直线是否合理、主体比例是否拉伸、裁去的范围是否可接受。四点变换针对一个平面，多深度场景不能整体同时变正；没有标定参数时不能声称精确消除镜头畸变。
