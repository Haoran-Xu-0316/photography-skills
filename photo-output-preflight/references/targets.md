# 交付目标

## Web

- 默认建议长边1600至2400像素。
- JPEG、PNG和WebP为常用格式；照片型内容默认JPEG质量95。
- 任何透明通道都进入复核清单。RGBA、LA和带调色板透明信息的图像必须以PNG副本保留透明度，不得静默压平或转为JPEG。
- 有ICC时转换或保留sRGB；无ICC时标记风险，不假定Adobe RGB或Display P3。
- 默认删除GPS，保留拍摄时间和相机信息由用户决定。

## Print

- 有效PPI按像素尺寸除以成品英寸计算。
- 300PPI为高质量目标，240至299PPI提示复核，低于240PPI阻断。
- 印刷色彩转换必须使用实际目标ICC。仅设置DPI元数据不能增加真实分辨率。

## Archive

- 保留原格式、位深和元数据，记录SHA-256。
- 不重新压缩、不改名覆盖、不删除原文件。
- 同名不同内容、哈希重复和缺少扩展名应进入复核清单。
