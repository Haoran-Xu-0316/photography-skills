# 局部光影调整

利用主体蒙版和同通道EV调整重新分配局部亮度，引导视线并强化照片已有光影。

## 输入与输出

输入为单张照片，可选用户蒙版。输出成片、主体蒙版、16bit EV光照图、对照板、配方和验证报告。

## 使用示例

> 按我提供的主体蒙版轻微提亮人物、压暗背景，让明暗过渡自然。

提供照片与需求后，按[执行说明](SKILL.md)处理。Python调用方式见[函数示例](examples/basic_usage.py)。

## 使用说明

调整基于照片已有的亮度信息；使用前需检查蒙版边缘，避免光晕和误选。


## 适合什么任务

适合主体不够突出、左右明暗失衡或已有光影较平的照片。通过空间蒙版分配局部亮度，保留原本的照明方向与物体结构。

## 如何准备素材和选择设置

提供照片，可附主体蒙版。focus用于主体与背景分离，depth强化已有明暗层次，balance缓和局部失衡。自动显著性蒙版不等于精准分割，复杂主体优先提供确认过的蒙版。

## 完整请求示例

> 按这张主体蒙版轻微提亮人物、压暗背景，保持脸部亮度自然，检查头发边缘有无光晕，同时输出蒙版和EV光照图。

这段请求可连同素材交给能读取本目录[执行说明](SKILL.md)的模型。图片处理需要相应Python依赖；生成式图片需要运行环境提供生图能力。文字对话本身不等于已经执行处理。

## 如何阅读和验收结果

对照板用于查看改变是否自然，EV图表示各处亮度增减。重点检查发丝、衣物边缘和高光剪切。该处理不新增轮廓光或投影，也不会把原有侧光变成另一方向的真实照明。
