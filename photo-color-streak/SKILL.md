# 照片横向拉丝重构

## 任务与能力

把照片背景重构为细密、平滑、连续的水平颜色拉丝，主体仍呈现自然摄影质感。拉丝来自颜色的横向延展，不能仅靠几根装饰亮线表现。

使用当前环境的看图与参考图生成能力，不依赖特定模型、厂商、Python或命令行。默认生成一张图片，沿用原照比例，不新增文字、边框、纸张或装饰。源图只读、成品另存，不自动安装、发布或推送。

只有文字能力时交付填写完整的提示并说明未生成；无法看图时标记待复核。生成式重构不能保证原始像素、细字与建筑细节不变。

## 一、先确定操作范围

- 用户要求创建或优化skill：编辑指令和说明。除非同时要求图片验证或示例制作，不调用生图、不更换示例。
- 用户提供照片要求效果图：执行下述生成流程。
- 用户只提供狭窄裁片要求这种质感：将裁片作为纹理或配色依据。编写规则无需完整照片；实际出图缺少目标照片时才请求原图。
- 用户要求只改质感：锁定现有构图、主体、画幅和摄影区边界，仅修改背景。

## 二、区分输入角色

原始照片是主体身份、结构、光线和摄影细节的依据。现有成品仅在需要保留其布局时作为构图依据，不把已绘画化的候选作为新的主体来源。

风格参考只提供指定维度：纹理、配色或构图。局部裁片默认只提供纹理与配色，忽略狭长画幅及旁边残留的主体。参考同时包含照片与拉丝时，明确提取哪一侧的拉丝，不让模型融合整张参考。

从原照记录三至五项保留事实：主体数量、轮廓、相对位置、遮挡、倒影或光向。另列可修改的背景区域及自上而下的颜色顺序。只记录当前图片事实，不凭地名常识补内容。

## 三、建立连续摄影区域

主体位置与比例跟随原照，有前景承托，不固定居中或统一宽度。

先按两个视觉层组织画面：下层是一张覆盖整个画幅的连续水平拉丝色场，上层是原照中需要保留的连贯摄影区域。这里描述的是生成画面的关系，不要求工具实际输出图层。顶部、左侧、右侧露出的拉丝均属于同一个下层，不能分别设计为天空背景和两条装饰边。

同一高度的色带在主体两侧应能对接，色相、亮度与条纹尺度保持连续；主体上方没有遮挡的区域应横贯全幅，不出现沿摄影区域侧边向上延伸的竖直拼接缝。主体遮挡可以中断可见色带，但不应改变其背后的延展方向。

- 建筑：保留建筑群及前景，上缘沿塔尖、屋脊变化，局部侧边可直切，不给每栋楼加贴纸边。
- 山水：山体、岸线、湖面与倒影保持连续，上缘随山脊起伏，侧切不能截断核心主体。
- 复杂主体：扩大保留区域，不为露出更多拉丝而抠碎枝叶、屋檐或人物。

侧边直切只定义摄影区域在哪里结束，不定义背景的独立分栏。不设置默认左右各占固定百分比的边条，也不缩小、压窄或强制居中照片来腾出色带。主体贴边时保留完整主体，利用实际可替换的背景形成效果；需要裁去核心内容或扩展画幅时先让用户决定，不能在修正提示中擅自放宽保留要求。

边界清楚但无白边、光晕、纸纤维和投影。不要移动地标、增加物件或把摄影区域改成插画。

## 四、拉丝材质

同时建立三个尺度：远看有连续宽色域，中距离有疏密不同的条带，近看有同色系深浅细丝。宽带承托细丝，不是在平涂背景上加几根亮线。

- 方向：严格水平，视觉上连续横贯背景；无斜向、放射、波浪轨迹或明显线段端点。
- 密度：线宽与间距自然变化，色域内部有细小色阶；不用等距扫描线或规则条码，不硬定条数。
- 清晰度：沿水平方向顺滑，垂直方向保留细密明暗变化。适度柔化锯齿，但不糊成单一渐变。
- 表面：颜色本身被拖长，形成细腻光学纹理；不把拉丝解释为金属划痕、织物经纬、立体凹槽或颗粒。
- 高光：浅线来自亮部延展，不自发光。避免霓虹、泛光、孤立粗白横杠；暗部仍能分出近黑、灰、青的层次。

纹理只作用于背景，不通过全图锐化、清晰度增强、绘画化或噪点制造质感。

## 五、颜色规则

默认从原照推导颜色，保持自上而下的空间顺序和明暗关系，天空、山体或建筑、地面或水面的颜色在相应高度横向延展。不随机排列主色，不把全图平均色铺成渐变。

有指定色彩参考时，提取主导冷暖、浅中深层次、饱和度及暖色占比，再映射到原场景的高度关系。参考仅影响背景；除非明确要求同步调色，不更改摄影主体。

用户指定的冷暖拉丝方向可表达为：浅部银灰与雾蓝，中部石板蓝灰，暗部深青与近黑，间以蜂蜜金、赭色和浅米灰。保持冷色深度和暖色克制，不变成荧光青与发光橙。这是特定参考的配色方向，不是通用固定滤镜。

没有要求换色时保留原照色系。没有取样工具时描述视觉颜色关系，不编造精确色值。

## 六、生成与有限修正

把任务写成明确的背景编辑，避免笼统要求整图艺术化。使用以下提示结构，将括号内容替换为实际观察结果，删除不适用项：

> 原图是主体与摄影细节的依据。参考图的【指定区域】仅用于【纹理或配色】。画面由一个全幅连续水平拉丝背景和其前方的连贯摄影区域组成。保留【主体数量、轮廓、位置、遮挡、光线和倒影】，保持自然摄影纹理。摄影区域覆盖【连贯区域】，边界沿【轮廓与必要侧切】；仅在【可修改区域】露出下层拉丝。顶部和两侧属于同一个背景，同一高度的色带能从左到右对接，主体上方无竖直分缝，不设置左右装饰边或三栏布局。背景由上至下为【颜色与明暗顺序】，宽色域内有密集同色深浅细丝，线宽与间距自然变化，顺滑而有层次，浅线不发光，暗部不糊成一块。保持【画幅】和主体比例，不为露出色带而裁去核心主体，不重调主体，不新增元素，不出现织物、金属凹槽、纸边、发光横杠、规则条码或全图模糊。

先生成一个候选，查看后最多两轮定向修正。每次只修主要问题，重申未改动项。主体绘画化时回到原照约束身份；工具支持可靠背景蒙版时优先限制区域，不假设所有工具都能锁定像素。

| 问题 | 修改方向 |
| --- | --- |
| 只有色块或平滑渐变 | 增加色域内部的近似色细丝，不加全图噪点 |
| 像扫描线或条码 | 打散等距和重复线宽，降低细线反差，保留宽色域 |
| 像霓虹或光轨 | 去掉自发光和泛光，让浅线回到照片亮部色阶 |
| 颜色过艳、质感生硬 | 降低背景局部饱和度与亮线反差，保留深色层次，不统一灰化 |
| 背景正确但主体绘画化 | 回到原照，仅限定背景修改，不用更强锐化补救 |
| 像矩形照片贴纸 | 让塔尖、山脊或屋顶突破上缘，保留必要侧切 |
| 只替换了天空 | 重新明确全幅背景与摄影保留区的关系，在实际可修改区域露出同一色场，不强加等宽边条 |
| 顶部与两侧拼接、像三栏相框 | 统一背景的横向色带与色阶，取消独立边条；摄影轮廓之外不保留竖直分界 |
| 白边或光晕 | 定向修边缘，不模糊整图 |

## 七、分开验收

先看完整画幅，再看背景局部和主体细节。仅见缩略图时，不宣称细纹、字迹及边缘通过。

1. 背景：在主体上方及两侧选取数个高度，检查可见色带是否横向对接；无独立左右边条或空背景中的竖直拼接缝。宽色域、条带、细丝均可辨，无规则条码、泛光横杠或错误材质，颜色对应本次原照或指定参考。
2. 主体：身份、数量、比例、遮挡与倒影连贯；山石、树叶、瓦片、窗格仍像摄影，没有涂抹、描边或绘画化。清楚不等于摄影质感保留。
3. 整体：摄影与拉丝有明确边界和轮廓穿插，不是居中照片套边框；无白边、光晕、意外裁切或画幅拉伸；主体比例、亮度与颜色未被无故改变。材质漂亮不能抵消构图失败。

三项都满足才标为完成。仅背景合格时标为材质候选；不能看图时标为待视觉复核。达到修正次数仍失败，说明具体缺陷，保留原图与已合格版本，不自动以候选替换示例。

交付图片、保存位置及一句生成式重构说明，保存实际提示。不承诺随机生成逐次一致。
