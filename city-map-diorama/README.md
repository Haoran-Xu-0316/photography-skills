# 地图立体城市

从城市主题生成与复古地图连续衔接的微缩城市画面，让道路、水面和地形从纸面自然过渡到立体景观。

## 输入与输出

输入城市、国家和希望突出的地标，可附地图或照片参考。输出一张地图与城市融合的图片。

## 使用示例

> 做一张悉尼地图立体城市图，突出歌剧院和海港大桥，让海岸与地图自然衔接。

使用时提供主题或参考图片，由具备图像生成与查看能力的模型按[执行说明](SKILL.md)完成。

## 使用说明

地图比例和街道经过艺术化处理，不用于导航或GIS，也不输出可旋转3D模型。


## 适合什么任务

适合制作旅行城市视觉、城市主题封面和地标展示。画面的关键是纸质地图逐渐变成立体城市：道路延续为街道，蓝色水系变成水面，地形逐步升起，而非把一座模型摆在地图上。

## 如何准备素材和选择设置

至少提供城市名称；同名城市应写明国家或地区。可补充重点地标、地图文字语言、横竖比例和参考地图。默认方形、暖米色纸面、柔和暖光与斜俯视，地标数量以能读清空间关系为准。

## 完整请求示例

> 请为巴黎制作一张方形地图立体城市图，以塞纳河组织画面，突出埃菲尔铁塔，保留地图向街道和水面的连续过渡。只放少量准确地名。

这段请求可连同素材交给能读取本目录[执行说明](SKILL.md)的模型。图片处理需要相应Python依赖；生成式图片需要运行环境提供生图能力。文字对话本身不等于已经执行处理。

## 如何阅读和验收结果

交付一张二维艺术图片。检查时重点看桥梁是否连接两岸、道路和水系是否连续、地标是否属于指定城市，以及地图与建筑之间是否出现生硬切割。艺术压缩后的距离和道路不能用于导航。
