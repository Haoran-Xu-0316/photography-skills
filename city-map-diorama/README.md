# 地图立体城市

从城市主题生成与复古地图连续衔接的微缩城市画面，让道路、水面和地形从纸面自然过渡到立体景观。

## 输入与输出

输入城市、国家和希望突出的地标，可附地图或照片参考。输出一张地图与城市融合的图片。

## 使用示例

> 做一张悉尼地图立体城市图，突出歌剧院和海港大桥，让海岸与地图自然衔接。

使用时提供主题或参考图片，由具备图像生成与查看能力的模型按[执行说明](SKILL.md)完成。
