# 工业产品爆炸图

将产品概念、物件照片或结构资料转为工业产品爆炸视图，通过分离的部件、共同装配轴和材质层次展示结构。

## 输入与输出

输入产品名称、照片或结构资料，以及材质与背景要求。输出一张产品组件爆炸图。

## 使用示例

> 做一个手摇咖啡磨豆器的概念爆炸图，采用金属与胡桃木材质，组件分离清楚，不加文字。

使用时提供主题或参考图片，由具备图像生成与查看能力的模型按[执行说明](SKILL.md)完成。

## 使用说明

内部结构可以是概念性推演，不能作为制造图纸、维修指令或真实结构证明。


## 适合什么任务

适合产品概念展示、组件层级说明和材质提案。将有解释价值的组件沿合理装配方向分离，让外壳、功能件和连接件的关系一眼可读。

## 如何准备素材和选择设置

提供产品名称或外观照片即可做概念图；需要忠实结构时，应补充零件清单、剖面图或装配资料。可指定材质、背景、视角和需要分离的组件组。默认浅冷灰背景、3:4竖版、无文字。

## 完整请求示例

> 根据这份手电筒结构资料制作爆炸视图，沿纵轴分离灯头、筒身、电池和尾盖，保留共同轴线与清楚间隙，金属表面采用克制高光。

这段请求可连同素材交给能读取本目录[执行说明](SKILL.md)的模型。图片处理需要相应Python依赖；生成式图片需要运行环境提供生图能力。文字对话本身不等于已经执行处理。

## 如何阅读和验收结果

交付结构展示图片。核对组件数量、装配顺序、孔位与共同轴线，避免重复零件或无法连接的部件。没有内部资料时，结果属于概念推演，不能据此制造或维修。
