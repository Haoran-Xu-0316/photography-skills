# 超现实尺度电影画面

将一个尺度异常的日常物体置于可信的摄影环境中，通过人物比例、空间距离、光线和接触关系形成电影感画面。

## 输入与输出

输入物体、场景和尺度关系，可指定时间、光线和镜头方向。输出一张超现实摄影风格图片。

## 使用示例

> 一只三层楼高的白瓷茶杯半埋在清晨沙漠，旁边有一个很小的人，其余环境保持真实摄影质感。

使用时提供主题或参考图片，由具备图像生成与查看能力的模型按[执行说明](SKILL.md)完成。

## 使用说明

画面是虚构创作；不同生成结果可能在阴影、纹理和次要细节上有所变化。


## 适合什么任务

适合概念视觉、电影感创意画面和以巨大日常物体表达孤独或压迫感的作品。用一个明确的尺度异常组织画面，其余环境遵循真实摄影逻辑。

## 如何准备素材和选择设置

提供日常物体、地点和情绪，可补充天气、时间、镜头方向或参考照片。默认16:9横幅、无文字；人物、门窗或道路作为尺度参照，帮助观众看懂物体有多大。

## 完整请求示例

> 一副巨大的眼镜静卧雪原，远处一名徒步者提供尺度参照，阴天冷光，镜框与积雪真实接触，采用远景电影构图，无文字。

这段请求可连同素材交给能读取本目录[执行说明](SKILL.md)的模型。图片处理需要相应Python依赖；生成式图片需要运行环境提供生图能力。文字对话本身不等于已经执行处理。

## 如何阅读和验收结果

检查主体是否接地、阴影是否统一、尺度参照是否清楚，材质是否仍像原物。示例属于虚构创作，不是真实事件记录；电影感应来自空间和光线，而不只是套色调。
