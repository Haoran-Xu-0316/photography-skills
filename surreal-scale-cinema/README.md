# 超现实尺度电影画面

将一个尺度异常的日常物体置于可信的摄影环境中，通过人物比例、空间距离、光线和接触关系形成电影感画面。

## 输入与输出

输入物体、场景和尺度关系，可指定时间、光线和镜头方向。输出一张超现实摄影风格图片。

## 使用示例

> 一只三层楼高的白瓷茶杯半埋在清晨沙漠，旁边有一个很小的人，其余环境保持真实摄影质感。

使用时提供主题或参考图片，由具备图像生成与查看能力的模型按[执行说明](SKILL.md)完成。
