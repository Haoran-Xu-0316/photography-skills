# 单张照片转3D

## 运行契约

- 核心入口是本目录的`SKILL.md`。`scripts`、`references`和`assets`路径必须相对本Skill根目录解析，不依赖特定模型、厂商工具名或提示词语法。
- 自动转换需要Python3.10+和`requirements.txt`中的依赖。执行代理应将本Skill的`scripts`目录临时加入当前Python进程的模块搜索路径，再调用下述接口。
- 用户提供深度图时不需要下载模型。自动估深还需要本地可用的模型权重；任何联网或权重下载都必须先取得用户明确许可。
- 最终验收需要查看深度检查图、视差预览或OBJ渲染。无法查看这些结果的模型只能交付待复核产物，不能宣称立体转换完成。

## 定位

从单张照片估计相对深度，并把可验证的正面结构转换为2.5D视差或高度场网格。输出保留原照片颜色和正面内容，不使用生成模型补造背面、遮挡区域或不可见几何。

单目深度是相对前后关系，不是实际米制距离。除非用户提供相机参数、标定尺度和多视角照片，不得把结果称为真实扫描、数字孪生或完整3D模型。

## 输出模式

- `depth`：输出16bit相对深度图和深度检查图。
- `parallax`：输出自包含交互HTML与循环视差GIF，适合场景、人像和社交展示。
- `relief`：输出带纹理的OBJ、MTL和纹理图，适合正面观看、网页展示和进一步建模。
- `bundle`：同时输出以上全部内容，默认模式。

用户要求“照片动起来”“鼠标视差”“3D照片”时优先`parallax`。用户要求OBJ、网格、浮雕或导入3D软件时使用`relief`。用户要求完整可旋转物体时，先说明单图限制；只有正面浅浮雕可在本skill内可靠完成。

## 工作流

1. 锁定当前用户照片，记录尺寸、方向和SHA-256。原图只读。
2. 优先使用用户提供的深度图。没有深度图时调用Depth Anything V2 Small生成相对深度。
3. 默认只从本地模型缓存加载。用户明确允许下载后才可从模型仓库获取权重。
4. 对深度结果做稳健归一化、边缘保留平滑和方向确认。默认白色表示近、黑色表示远。
5. 生成深度检查图。深度范围塌缩、出现非有限值或主体前后关系明显错误时停止，不继续制作3D结果。
6. 按模式生成交互视差、动画或OBJ浅浮雕。
7. 运行验证，检查原图未改变、深度有效、HTML资源完整、动画帧数和OBJ顶点面数量。
8. 交付最终文件、配方JSON和验证JSON。中间文件不得冒充最终结果。

## 程序化接口

本skill不提供面向用户的命令行工具。把`scripts`目录加入Python路径后调用：

```python
from photo_to_3d import analyze_photo, estimate_depth, convert_photo_to_3d

analysis = analyze_photo(input_path)
depth = estimate_depth(input_path, output_dir, depth_map_path=optional_depth)
result = convert_photo_to_3d(
    input_path,
    output_dir,
    mode="bundle",
    depth_map_path=optional_depth,
)
```

`allow_model_download=False`是默认值。只有用户明确同意下载模型时才设为`True`。

## 核心约束

- 原照片不得裁切、重绘、调色、磨皮或生成式延展。
- 深度图只能表达相对远近，不能推导真实物理尺寸。
- 视差强度默认使用图像宽度的2%，通常不超过3%，硬上限4%，避免边缘拉裂和眩晕感。
- 浅浮雕默认深度为平面宽度的12%，网格长边默认256个采样点。
- OBJ只能保证正面高度场，不保证背面、侧面、薄结构和遮挡关系真实。
- 人脸、文字、栏杆、树叶、透明体、镜面和反射区域必须重点检查深度边缘。
- 用户提供的深度图优先级高于模型估计。方向不一致时允许显式反转，不凭猜测静默反转。
- 用户深度图必须与原照片保持同一宽高比和逐像素对应关系；允许等比缩放，不允许拉伸，不得把原照片自身当作深度图。
- 输出已存在时默认失败，不覆盖原图或既有结果。

## 按需读取

- 生成或检查深度图时读取[references/depth-estimation.md](references/depth-estimation.md)。
- 生成视差或OBJ时读取[references/output-modes.md](references/output-modes.md)。
- 用户要求完整3D、打印、真实尺度或大角度旋转时读取[references/limitations.md](references/limitations.md)。

## 交付标准

- 深度图与原图尺寸一致，近远方向明确，具有有效动态范围。
- 交互视差在桌面和触摸输入下可恢复到中心位置，照片边缘不露透明洞。
- GIF循环首尾连续，不出现整图平移冒充深度视差。
- OBJ包含有效UV、纹理和非零深度范围，能被标准3D软件读取。
- 配方记录模型、深度方向、视差强度、网格分辨率和全部输出文件。
