# 照片微缩景观

把照片中的建筑、街角、庭园或自然场景重建为白底写实微缩景观，保留主要空间关系，呈现模型的厚度、材质和接触阴影。

## 输入与输出

输入一张照片，可指定需要保留的主体和构图。输出微缩景观图片，也可制作原照与微缩图的对照海报。

## 使用示例

> 把这张庭园照片做成白底写实微缩景观，保留水池、桥和植被的位置，再制作原照对照海报。

使用时提供主题或参考图片，由具备图像生成与查看能力的模型按[执行说明](SKILL.md)完成。

## 使用说明

输出是具有立体观感的二维图片，不是扫描模型。可选海报排版工具见[函数示例](examples/basic_usage.py)。


## 适合什么任务

适合将建筑、庭园、街角或自然场景制作成白底收藏模型观感。重建照片可见的空间关系，表现模型厚度、材质、支撑和接触阴影。

## 如何准备素材和选择设置

提供一张照片，注明必须保留的主体、连接关系和可简化背景。可选择独立微缩图或原照对照海报；标题与地点由用户提供。默认方形微缩图，海报默认3:4竖版。

## 完整请求示例

> 把这张运河照片重建为白底微缩景观，保留桥梁、两岸建筑和水道走向，主体四周留白。再用已生成的微缩图制作上原照、下模型的对照海报。

这段请求可连同素材交给能读取本目录[执行说明](SKILL.md)的模型。图片处理需要相应Python依赖；生成式图片需要运行环境提供生图能力。文字对话本身不等于已经执行处理。

## 如何阅读和验收结果

检查桥路连接、物体数量、主体完整度和材质是否可信。微缩结果允许空间压缩，但不能随意改变主要位置。成品是二维图片；补出的侧面和厚度不是对真实隐藏结构的测量。
