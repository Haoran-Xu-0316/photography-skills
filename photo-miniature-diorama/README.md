# 照片微缩景观

把照片中的建筑、街角、庭园或自然场景重建为白底写实微缩景观，保留主要空间关系，呈现模型的厚度、材质和接触阴影。

## 输入与输出

输入一张照片，可指定需要保留的主体和构图。输出微缩景观图片，也可制作原照与微缩图的对照海报。

## 使用示例

> 把这张庭园照片做成白底写实微缩景观，保留水池、桥和植被的位置，再制作原照对照海报。

使用时提供主题或参考图片，由具备图像生成与查看能力的模型按[执行说明](SKILL.md)完成。
