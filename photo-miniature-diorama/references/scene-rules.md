# 按场景选择微缩结构

这些是选择标准，不是要求机械使用全部模式。混合场景由主要辨识物决定结构。

| 场景 | 推荐结构 | 不应丢失的关系 | 高风险问题 |
|---|---|---|---|
| 街区 | 薄矩形或街区轮廓切片 | 路口连接、街道方向、建筑高低与招牌色块 | 道路断开、楼体融合、无依据增建 |
| 室内 | 开放顶面与必要侧墙的剖面 | 柱网、家具组团、主要背景墙 | 移除承重柱、家具穿插、改成室外 |
| 旋梯及单体建筑 | 独立主体或局部剖开结构 | 楼层节奏、梯段连续性、外立面特征 | 编造楼层、旋梯无入口、栏杆断裂 |
| 海岸与港口 | 岸线主导的地形切片 | 防波堤、船群分布、对岸与前景次序 | 海水立成墙、码头漂浮、岸线改向 |
| 山体湖泊 | 圆润或不规则地形切片 | 山形、雪线、湖岸、游船与地标位置 | 山体被拉成薄背景板、距离压缩导致前后颠倒 |
| 庭园器物 | 包含局部环境的紧凑景观 | 竹管出口、水流、容器、石头和植物关系 | 水流接错、碗口封闭、添造装饰 |
| 池塘与动物 | 自然池岸围合的浅地形 | 鱼的可辨数量与色型、池岸、石块和水面 | 增减显著鱼、鱼浮在水上、水面成为玻璃罩 |
| 车辆街景 | 车辆加必要街角环境 | 车身形状、轮轴、涂装色块、护栏与立面 | 车辆变款、额外轮胎、护栏穿车 |

## 压缩而不改写

- 保留前景、中景、后景的相对顺序，缩短空旷地面或水面距离。
- 少量高辨识地标保细节，重复且次要的树叶、窗户、行人压缩密度。
- 前景遮挡只有在妨碍核心主体辨识时才减少；有叙事作用的遮挡保留。
- 剖面开口用于展示可见室内关系，不是复原照片之外的整栋建筑。
- 建筑顶部被照片裁断时，保留立面的水平剖切终止面，不默认补完整屋顶、烟囱或额外楼层。先明确裁断边界，再描述侧面厚度，避免“完整模型”被误解为补全整栋楼。
- 动物场景先保留可见肢体、尾部、姿态与承托物，再收束环境；不能为了底座规整裁去尾巴或让脚悬空。
- 低云可做轻薄局部雾层；它必须服务原图场景，不能变成通用奇幻装饰。
- 不承诺车牌、品牌小字或远处招牌逐字准确。用户明确要求精确文字时需单独核对或后期处理。

## 无法可靠处理时

纯人脸特写、大片天空、主体严重遮挡或极低清照片，不宜直接推断完整场景。说明哪部分信息不足，提供局部微缩方案或请求更合适的照片，不把它强行转成无关沙盘。
