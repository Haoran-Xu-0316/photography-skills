# 创意调色规范

## 目标规格

任何创意方向都必须转成可执行的色彩关系：

- 整体明度与黑位密度
- 对比强度与高光过渡
- 主色温和辅助色温
- 高光、中间调和阴影的色相关系
- 全局饱和度与局部饱和度分配
- 主体和背景的颜色优先级
- 肤色、天空、植被等敏感区域的保护策略

不要仅使用“电影感”“高级感”“氛围感”等词语作为执行参数。

## 内置目标

- `natural-clean`：低痕迹、自然准确，适合作为默认基础成片。
- `warm-documentary`：高光温暖、阴影略冷，保留真实肤色和环境层次。
- `cool-urban`：中性偏冷、结构清楚，暖色主体成为视觉强调。
- `muted-editorial`：降低非主体颜色密度，反差柔和，强调内容与留白。
- `soft-film`：柔和高光、轻微抬黑和克制色彩分离，不冒充具体胶片品牌。

这些定义是目标范围，不是固定滤镜。实际强度必须根据原图亮度、综合色偏和饱和度自适应。

## 预览

预览同时给出技术校色和目标强度70%、100%、130%。比较时优先检查：

1. 主体是否更清楚，而不是全图更艳。
2. 肤色是否连续、自然，没有橙化、粉化或灰化。
3. 高光是否保留颜色和纹理。
4. 阴影是否有密度而不脏。
5. 强调色是否集中，背景是否得到约束。

用户选择方向后记录look名称、强度和技术底片参数，批量时不重新猜测创意方向。

## 禁止

- 不同时叠加多个look。
- 不把全局色温变化当作完整创意调色。
- 不用过量青橙、紫绿对比制造廉价电影感。
- 不自动美白、磨皮、改变嘴唇或眼睛颜色。
- 不使用生成模型改变局部颜色或内容。
