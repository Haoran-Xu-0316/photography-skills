# 参数参考

配置文件在`assets/default.yaml`。程序化接口通过`overrides`字典覆盖点路径参数。

```python
analysis = analyze_photos(
    photo_directory,
    report_directory,
    overrides={
        "sharpness.sharp_width": 0.70,
        "burst.keep_per_group": 2,
    },
)
```

## 阈值的量纲

清晰度阈值单位是归一化边缘宽度，1.0对应西门子星标定的完美锐边。数值只在统一的工作分辨率下可比，本工具固定长边1400。

长边1400下的实测参考值：

| 状态 | 峰值边缘宽度 |
|---|---|
| 清晰 | 0.65到0.70 |
| 轻度失焦，模糊半径2像素 | 0.76 |
| 中度失焦，模糊半径4像素 | 0.93 |
| 重度失焦，模糊半径8像素 | 1.31 |

局部各向异性参考值：清晰0.03，浅景深0.09，失焦0.14到0.26，抖动0.52到0.60。

## sharpness

| 参数 | 默认 | 说明 |
|---|---|---|
| sharp_width | 0.75 | 低于此值判为锐 |
| soft_width | 1.15 | 高于此值判为失焦 |
| reject_width | 1.30 | 高于此值才允许自动判废 |
| anisotropy | 0.35 | 方向性高于此值判为抖动 |
| edge_percentile | 90 | 取最强的百分之十边缘参与统计 |
| tiles | 12 | 分块数，用于定位最锐区域 |

判废门槛必须明显高于判优，两者之间是待定区。缩小这个区间会提高自动化程度但增加误删风险。

老镜头、软焦镜头、加了柔光滤镜的片子整体宽度偏大，遇到判废比例异常高时先确认是不是器材本身的特性，而不是直接怀疑对焦。

## exposure

| 参数 | 默认 | 说明 |
|---|---|---|
| warn_highlight_pct | 3.0 | 高光溢出提示阈值 |
| reject_highlight_pct | 12.0 | 高光溢出判废阈值 |
| reject_shadow_pct | 45.0 | 暗部死黑判废阈值 |
| flat_threshold | 0.45 | 相对反差低于此值判为误拍或遮挡 |

反差用相对值而非绝对值。绝对反差会把欠曝误判成误拍，而欠曝在RAW里可以提亮回来。镜头盖误拍则是无论怎么归一化都平。

逆光、日出日落、舞台灯光这类题材高光溢出本来就高，建议把`reject_highlight_pct`调到20以上，否则会大量误杀。

## faces

| 参数 | 默认 | 说明 |
|---|---|---|
| enabled | true | 非人像题材建议关闭，省三成时间 |
| min_face_ratio | 0.04 | 人脸最小尺寸占画面短边的比例 |
| focus_tolerance | 0.18 | 对焦落点与人脸中心的容许距离 |

用OpenCV自带的Haar级联，只能测正脸，侧脸和低头会漏。漏检不产生任何判定，因此不会造成误杀，只是少了一道检查。

## burst

| 参数 | 默认 | 说明 |
|---|---|---|
| enabled | true | |
| max_hash_distance | 10 | 感知哈希汉明距离上限，越小分组越严 |
| max_gap_sec | 3.0 | 相邻两张的时间间隔上限 |
| keep_per_group | 1 | 每组保留几张为keep，其余降为待定 |
| require_time | false | 缺少EXIF时间时是否仍要求时间条件 |

时间戳缺失时自动回退到文件修改时间。若完全没有时间信息且`require_time`为false，分组退化为纯哈希匹配，同一场景的不同构图可能被错误合并。批量导出的JPEG常常丢失原始时间，遇到分组异常时先检查这一项。

打鸟这类高速连拍建议把`max_gap_sec`压到1.5，避免把两次不同的扑击并成一组。风光的包围曝光间隔长，需要放宽到8秒以上。

## labels

色标名称，Lightroom与Capture One通用。可选red、yellow、green、blue、purple。

| 键 | 默认 | 对应 |
|---|---|---|
| best | green | 连拍组内最优，五星 |
| keep | green | 未检出问题，四星 |
| review | yellow | 待定，三星 |
| reject | red | 判废，一星 |

## 预设

| 预设 | 场景 | 主要改动 |
|---|---|---|
| wildlife | 打鸟高速连拍 | 锐度更严0.70，抖动更敏感0.30，连拍间隔1.5秒，每组留2张，关人脸检测 |
| portrait | 人像浅景深 | 锐度放宽0.82，对焦落点容差收紧0.14，每组留2张 |
| landscape | 三脚架风光 | 锐度最严0.70，判废门槛1.20，连拍间隔放宽到8秒，关人脸检测 |
| street | 手持抓拍 | 锐度放宽0.85，判废门槛1.60，宁留勿删 |

预设定义在`assets/default.yaml`末尾，可直接增改。

## 程序化参数

| 参数 | 默认 | 说明 |
|---|---|---|
| preset | 无 | 题材预设 |
| overrides | 无 | 以点路径为键的参数覆盖字典 |
| jobs | 1 | 并行进程数 |
| output_dir | 必填 | 独立报告输出目录 |
| config_path | assets/default.yaml | 配置文件路径 |

并行只影响速度，不影响结果。排查问题时使用`jobs=1`，异常定位更直接。
