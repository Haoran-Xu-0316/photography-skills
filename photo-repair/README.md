# 照片技术修复

诊断并修复照片采集阶段的技术缺陷，包括高ISO噪点、径向暗角、横向色差、坏点和热噪点。

## 输入与输出

输入为一张或多张照片。流程先输出诊断，再生成100%裁切预览，确认力度后写入独立修复目录。原文件始终只读。

## 使用示例

> 给这张高感照片做降噪，先提供局部对照，尽量保留毛发和纹理。

提供照片与需求后，按[执行说明](SKILL.md)处理。Python调用方式见[函数示例](examples/basic_usage.py)。
